# Cancer Data Analysis — Power BI

## Project Overview

This project presents an interactive Power BI dashboard exploring cancer statistics from 2012 to 2018, with a focus on cancer incidence, mortality, cancer stages, geographic patterns, and gender-based differences in lung cancer.

The goal is to transform complex healthcare data into accessible visualizations that support exploratory analysis and comparison.

## Dashboard Features

### 1. Cancer Insights Overview
- Summary indicators for cancer cases and deaths.
- Comparison of cases and deaths across cancer categories.
- Cancer-type filtering.
- Analysis of cancer stages in Armenia.
- Interactive navigation between dashboard views.

### 2. Lung Cancer Analysis
- Separate male and female lung cancer views.
- Regional comparisons of incidence and mortality.
- Geographic visualizations.
- Identification of countries with the highest and lowest displayed lung cancer values.
- Regional filters for exploring different geographic areas.

## Key Observations

- Lung cancer represents a prominent category in the dashboard's case and mortality comparisons.
- The displayed male lung cancer values are particularly high for Hungary, Serbia, Turkey, Greece, and Montenegro.
- The female lung cancer view highlights Hungary, Denmark, the Netherlands, Iceland, and Serbia among the highest displayed values.
- The Armenia stage IV visualization shows differences across cancer types, with lung cancer having the largest displayed value.

These observations describe the dashboard's displayed data and should be interpreted according to the original dataset's measures and units.

## Tools and Skills

- **Power BI Desktop** — Dashboard development and interactive reporting
- **Data Visualization** — Bar charts, treemaps, maps, and KPI indicators
- **Exploratory Data Analysis** — Comparison of cancer statistics
- **Interactive Reporting** — Filters, navigation, and dashboard interactions
